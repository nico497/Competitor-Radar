How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one for a mid-market ecommerce brand, TaxCloud or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), logged out of ChatGPT so there's no memory or personalization.
  • Open comparison question: "TaxCloud vs. {rival}: which should I choose?" Asked once per order (12 answers) — this is where the qualitative reasoning and citations below come from. It is not repeated, so a single odd answer could be noise.
  • Both orders are asked because ChatGPT can lean toward whichever brand is named first. For Avalara, TaxJar and Anrok it doesn't matter — the result is unanimous either way. For Numeral, Zamp and Kintsugi, the result varies run to run regardless of order — that's instability, not a clean order bias.
  • Not yet covered: pricing, integrations, filing, setup and support as separate scored dimensions (the first mockup of this page showed those; they'd need their own repeated, structured prompts to be real rather than invented). Also not covered: any engine besides ChatGPT, and any run while logged in.
